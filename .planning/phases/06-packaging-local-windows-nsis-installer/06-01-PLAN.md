<objective>
Produce the committed placeholder application icon (D-03): a zero-dependency Node script that writes a valid multi-byte Windows `.ico` at `build/icon.ico`, plus a binary-parse test proving the file clears electron-builder's 256x256 minimum. This is the icon half of PKG-04 and is fully cross-platform automatable — no Wine, no electron-builder needed to verify it.

Purpose: electron-builder's Windows target hard-fails if `win.icon` is missing or below 256x256 (RESEARCH Pitfall 3). This plan guarantees a valid icon asset exists and is regenerable, so the icon is never the reason a build fails. The icon is an explicitly throwaway monogram — swappable later by replacing one file, no config change (D-03).

Output: `scripts/make-icon.mjs`, the committed `build/icon.ico`, and `test/packaging.icon.test.ts`.
</objective>
