<objective>
Establish the two type contracts the whole parser is built on: the **FieldTable** (the sole home of byte offsets) and the **offset-free ViewModel**. Deliver `field-table.ts` (FieldEntry discriminated union + builder + typed ParseError + D-03 candidate model) and `view-model.ts` (types only, offset-free by construction). Provide the shared test harness: a fixture-decompress helper and the recursive no-offset scanner that enforces SC-4 at runtime.

Purpose: Every downstream parser (Wave 2) emits `FieldEntry` and every projection (Wave 3) targets `ViewModel`. Locking these contracts first lets the three region parsers build in parallel against a stable shape, and makes SC-4 (no offsets in the view model) and SC-2/SC-3 (authoritative/mirror/candidate flags) true by type construction rather than by convention.

Output: `src/field-table.ts`, `src/view-model.ts`, `test/helpers/fixture.ts`, `test/helpers/no-offset-scan.ts`, `test/field-table.test.ts`.

Note (provisional decisions in play): the ViewModel shape encodes D-01 (lean + free metadata: `isPlaceholder`/`isLocked` per stack, `entityIds` list) and D-02 (raw namespaced IDs, no name table — an optional `name` field is intentionally NOT added but the shape leaves room for it). These are PROVISIONAL user defaults; if the user later narrows the view model, only this file's types and the Wave 3 projection change.
</objective>
