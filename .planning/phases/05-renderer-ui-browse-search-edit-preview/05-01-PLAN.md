<objective>
Make bank item quantities addressable by the renderer without leaking offsets. Today the FieldTable keys bank stacks as `bank.inventory.<itemId>@<qtyOffset>` (offset embedded in the key) while the offset-free `ViewModel.BankItem` exposes no key at all — so the renderer cannot construct an edit payload for a quantity change, and duplicate itemIds across tabs are indistinguishable. This blocks EDIT-02.

Re-key bank stacks to an offset-free, deterministic `bank.inventory.<itemId>#<occurrenceIndex>` and surface that exact key on `BankItem.fieldKey`. The FieldEntry still carries the real byte offset internally (patcher unchanged); only the key STRING becomes offset-free, which strictly improves SC-4.

Purpose: Unblock EDIT-02 renderer addressing while preserving SC-4 (no offset at any depth in the ViewModel) and the frozen "no new IPC channel" contract — main still resolves by fieldKey.
Output: `BankItem.fieldKey`, an offset-free bank key scheme, and green core tests.
</objective>
