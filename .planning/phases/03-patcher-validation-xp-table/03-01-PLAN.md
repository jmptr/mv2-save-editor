<objective>
Build the verified StandardExperienceTable (`src/experience-table.ts`): a pure numeric module
that maps skill Level -> minimum XP (`xpForLevel`) and XP -> derived Level (`levelForXp`),
precomputed once at module load for levels 1..120. This is the single source of the XP<->Level
mapping that plan 03-02's patcher uses to keep a skill's XP and Level consistent on disk (EDIT-04).

The algorithm is ported 1:1 from `docs/current-skill.md` §"XP Table" (scaling=0.25,
exponent_scaling=300.0, base=2^(1/7)); RESEARCH executed it in-session and it reproduces the
SC-3-locked milestones exactly.

Purpose: EDIT-04 requires the app to auto-compute the correct XP for a target Level. A wrong
formula silently corrupts every skill edit, so correctness here is gated by the SC-3 milestones
before the patcher can rely on it.
Output: `src/experience-table.ts` + `test/experience-table.test.ts` (RED-first, then GREEN).
</objective>
