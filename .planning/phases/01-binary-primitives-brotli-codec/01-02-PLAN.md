<objective>
Implement the Brotli codec (src/codec.ts) and its full test suite (test/codec.test.ts). This is the IO-03 proof: a no-op load→save round-trips a real .sav to a byte-identical decompressed buffer with the length invariant asserted, using standard-parameter RFC 7932 Brotli (no large-window) that .NET can read. Defensively rejects the large-window param and caps decompression to mitigate bombs. Implements decisions D-02 (deepStrictEqual), D-04 (c8 coverage gate), D-07/D-08 (tsc strict), D-09/D-11 (single fixture, decompress at runtime), D-13 (no .NET SDK).

Purpose: The codec is the corruption-prevention spine. Every later phase (2-5) consumes decompress/compress; the length invariant is the first correctness gate. Getting this byte-exact against the real fixture removes the single biggest risk ("can Node's Brotli produce output .NET can read?") — already empirically closed by research, now locked by tests. Mitigates T-1-03 (decompression bomb) and T-1-05 (large-window corruption).

Output: src/codec.ts (compress, decompress, roundTrip, CODEC_PARAMS, MAX_DECOMPRESSED_BYTES) + test/codec.test.ts (real-fixture round-trip, per-quality round-trip, length invariant, bomb cap, large-window rejection, idempotent decompress).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .sav file bytes → codec decompress | Untrusted-origin compressed bytes cross here (a user-supplied .sav could be a decompression bomb) |
| codec compress → .NET decoder | Output must remain RFC 7932 standard (no large-window) or .NET cannot decode it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-03 | Denial of Service (decompression bomb) | decompress (brotliDecompressSync) | medium | mitigate | decompress passes maxOutputLength: MAX_DECOMPRESSED_BYTES (256 MiB) to brotliDecompressSync; oversized input throws. Bomb-cap test in test/codec.test.ts asserts the throw. |
| T-1-05 | Tampering (corruption) / DoS (game fails to load) | compress (large-window Brotli param) | medium | mitigate | compress defensively rejects the large-window param set to true with a throw. CODEC_PARAMS is frozen and excludes it. Large-window-rejection test asserts the throw. |
| T-1-SC | Tampering (supply chain) | npm devDeps | high | mitigate (owned by Plan 01) | Plan 01 Task 2 blocking checkpoint verified legitimacy before install. |
| T-1-01 | Tampering (wrong-width / wrong-endian write) | binary-writer | medium | mitigate (owned by Plan 03) | Plan 03 BinaryWriter LE-only API + negative tests. |
| T-1-02 | Denial of Service (7-bit length-prefix overflow) | binary-reader readString | medium | mitigate (owned by Plan 03) | Plan 03 rejects prefixes exceeding 5 bytes with RangeError. |
| T-1-04 | Tampering / Information Disclosure (buffer over-read OOB) | binary-reader | medium | mitigate (owned by Plan 03) | Plan 03 uses Buffer.readXxxLE + noUncheckedIndexedAccess. |
</threat_model>
