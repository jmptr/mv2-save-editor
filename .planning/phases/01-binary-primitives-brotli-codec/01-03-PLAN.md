<objective>
Implement the little-endian BinaryReader/Writer (src/binary-reader.ts + src/binary-writer.ts) and their full edge-matrix test suite (test/primitives.test.ts). The primitives match .NET BinaryReader/BinaryWriter byte-for-byte: int32 (4B), int64 (8B BigInt), double (8B IEEE 754), bool (1B), and 7-bit-length-prefixed UTF-8 strings. Wrong-width and wrong-endian writes are caught by negative tests (SC-4), never silently corrupting neighbors. Implements decisions D-02 (deepStrictEqual), D-04 (c8 gate), D-08 (noUncheckedIndexedAccess), D-12 (hand-crafted + fixture slices), D-13 (no .NET SDK), D-14 (full edge matrix), D-15 (inline vectors). Mitigates T-1-01 (wrong-width/endian), T-1-02 (7-bit overflow), T-1-04 (OOB read).

Purpose: These primitives are the foundation Phase 2's FieldTable parser and Phase 3's patcher consume. Every GP/item/skill edit in Phases 3-5 flows through these read/write methods. Getting them byte-exact against .NET (proven by the D-12 fixture slices) removes the second corruption risk after the codec.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| decompressed buffer → BinaryReader | Untrusted-origin bytes (decompressed from a user .sav) cross here; OOB reads and oversized length-prefixes must throw, not silently read undefined or allocate giant buffers |
| BinaryWriter → buffer | The writer must only emit LE bytes at the correct width; a wrong-width or wrong-endian write silently corrupts neighbors (Phase 2/3 callers depend on correct width) |
