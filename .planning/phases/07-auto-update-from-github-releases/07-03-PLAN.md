<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Releases feed → installed app | At real update time the app downloads and executes an installer binary from the remote feed (Phase 8 onward) |
| unsigned installer → Windows user | SmartScreen presents an "unknown publisher" prompt for the unsigned `.exe` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering | Downloaded update installer binary | high | mitigate | electron-updater's built-in SHA512 verification of the downloaded file against `latest.yml` before applying (no app code); confirmed by the Phase 8 two-release install. |
| T-07-03 | Spoofing (user trust) | Unsigned installer / SmartScreen | low | accept | Documented + accepted (REQUIREMENTS Out-of-Scope); code signing deferred to v2 (DIST-03). The update mechanism works unsigned on Windows. |
</threat_model>
