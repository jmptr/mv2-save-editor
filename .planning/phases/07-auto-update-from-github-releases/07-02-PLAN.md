<objective>
Build the main-process updater seam: a small `electron/updater.ts` helper (a zero-dep fs logger + a
guarded `initAutoUpdater()` that sets the logger, attaches the REQUIRED error trap, and makes the one
launch check), wired into `electron/main.ts` behind an `app.isPackaged` guard. This is the "behavior
half" of the phase — it turns locked decisions D-01..D-05 and D-08 into running code, kept strictly
inert in dev.

Purpose: deliver UPD-01 (launch check + background download), UPD-02 ("update ready" notification +
install-on-quit via defaults), and UPD-03 (inert in dev) — with failure isolation so an
offline/rate-limited/feed-absent run (the feed does not exist until Phase 8) never blocks the editor.

Output: `electron/updater.ts`, the guarded init call in `electron/main.ts`, and two static/behavioral
tests (`test/updater.logger.test.ts`, `test/updater.seam.test.ts`).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| packaged main process → GitHub Releases feed | The updater fetches a remote `latest.yml` + installer over the network — untrusted remote content crosses into the app |
| packaged vs dev run | `app.isPackaged` is the boundary that keeps the whole updater seam inert during `npm start` / `electron .` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-04 | Denial of Service | `autoUpdater` error channel in `electron/updater.ts` | high | mitigate | Attach `autoUpdater.on('error', …)` (an unhandled error event throws) AND `.catch()` on the promise; both log-only. `app.isPackaged` guard makes dev fully inert (D-03/D-05). |
| T-07-05 | Denial of Service | Absent Releases feed (no `latest.yml` until Phase 8) | medium | accept | Expected + correct pre-Phase-8: the error is swallowed + logged; the editor runs normally. A logged feed-404 in Phase 7 is NOT a failure (Pitfall 2). |
| T-07-02 | Tampering / Info Disclosure | Update feed/asset transport | low | mitigate | Rely on electron-updater's HTTPS-only fetch default; the seam never calls `setFeedURL` to a plaintext channel. |
</threat_model>
