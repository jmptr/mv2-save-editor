<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer page ↔ preload (isolated world) | Only the four exposed methods may cross; the page has no other privileged surface. |
| renderer ↔ remote content | The window must never load or execute remote resources. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-4-01 | Elevation of Privilege | preload contextBridge surface | critical | mitigate | Expose only four purpose-specific wrappers on `window.saveEditor`; never expose `ipcRenderer`/`.on`/a generic channel passthrough, so the page cannot reach arbitrary IPC or Node (SC-2). |
| T-4-07 | Tampering / Spoofing | index.html content loading | high | mitigate | Strict CSP (`default-src 'self'; script-src 'self'`), no inline scripts, local `renderer.js` only — no remote content can execute (the BrowserWindow `loadFile` + navigation deny land in Plan 05). |
| T-4-03 | Information Disclosure | renderer state | medium | mitigate | The renderer holds no fs path, no buffer, no offset, no session handle — it only calls the four methods and renders offset-free results. |
</threat_model>
