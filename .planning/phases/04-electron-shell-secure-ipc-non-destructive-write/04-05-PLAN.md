<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → main (IPC) | The four channels are the only entry to fs/Brotli/offsets; main is the trust boundary. |
| main → OS (file open/write, window) | Native dialogs + BrowserWindow; must stay local and non-destructive. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-4-01 | Elevation of Privilege | BrowserWindow webPreferences | critical | mitigate | `contextIsolation:true` + `nodeIntegration:false` + `sandbox:true` + compiled preload; renderer cannot reach Node/fs/Brotli (SC-1). |
| T-4-02 | Tampering | ipcMain.handle('save:preview'/'save:write') | high | mitigate | Each handler runs `assertEditsPayload` (shape) then `patchSave` re-resolves + re-validates against main's own FieldTable before any write (SC-4). |
| T-4-04 | Tampering / Repudiation | save:write handler | critical | mitigate | Delegates to `performWrite` — new-path-only, source-path rejected, length invariant asserted; original never opened for write (IO-02, D-03). |
| T-4-07 | Tampering / Spoofing | window navigation / new windows | high | mitigate | `loadFile` local only; `setWindowOpenHandler(() => deny)`; block `will-navigate`; no `remote` module. |
| T-4-11 | Information Disclosure | IPC handler exceptions | medium | mitigate | `toErrorResult` returns a discriminated result for every error; raw exceptions/stack/offsets never cross the bridge (D-04). |
</threat_model>
